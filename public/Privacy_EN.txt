3. Locally stored data

Some applications may store configuration data on the device, for example:
* Tempo, meter or sound preferences.
* Tuning settings.
* Transposition settings.
* Visual or functional preferences.
* Musical data entered by the user.
* Internal options needed to remember the app's state.

This data remains on the user's device, unless the operating system or the user makes backups through external services such as iCloud or other Apple mechanisms.
iDoctor Music Tools does not directly access those backups nor control Apple's processing of them.

4. Microphone use

Some applications, such as those related to tuning or sound analysis, may request access to the device microphone.
Microphone access is used exclusively for musical features, such as detecting the frequency of a note, helping tune an instrument or analyzing an audio signal in real time.
Audio captured by the microphone is not recorded, stored or sent to external servers by iDoctor Music Tools, unless a future version expressly states otherwise and requests the corresponding consent.
The user can grant or revoke microphone access at any time from the device privacy settings.

6. Third-party services

The applications may use services provided by Apple that are necessary for the normal operation of an iOS app, such as App Store distribution, in-app purchases, basic system analytics or Apple platform notifications, where applicable.

Some applications include specific external services, always under the user's control:

iCloud backup (iDoctor Beatbuddy Assistant): the app may store the user's analysis history in the private iCloud Drive container linked to their Apple ID, for the sole purpose of preserving it when switching devices or reinstalling the app. Only the user has access to that container; iDoctor Music Tools cannot see or process that data. Apple's processing is governed by Apple's own privacy policy.

Artificial-intelligence features with the user's own key (iDoctor Beatbuddy Assistant): optionally, the user may enter their own Anthropic (Claude) API key to refine analyses. The key is stored exclusively in the device Keychain and is used only for direct, encrypted calls to api.anthropic.com. Those calls include only the musical analysis metrics (tempo, groove, meter) and the song's file name; the audio itself is never sent. Anthropic's processing of that data is governed by its privacy policy (https://www.anthropic.com/legal/privacy). If the user does not enter a key, the app makes no external connection at all.

Should any application incorporate additional external services in the future, such as advanced analytics, cloud storage, sign-in, cross-device sync or error-diagnostics tools, this policy will be updated to clearly reflect it.
